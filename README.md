# 🎓 Academic Performance Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **Academic Performance Dashboard** created using **Microsoft Power BI**.

The dashboard analyzes student academic performance, attendance, behavior, subjects, classes, sections, and term-wise performance.

The main goal of this project is to transform raw student data into meaningful and interactive visual insights that can help understand overall academic performance.

---

## 🎯 Project Objectives

- Analyze overall student performance
- Track average student scores
- Monitor attendance percentage
- Compare performance across different subjects
- Analyze performance by class and section
- Track performance trends across terms
- Understand different student behavior types
- Identify low, medium, and high-performing students
- Provide interactive filtering for academic analysis

---

---

## 📈 Key Metrics

### Total Students

Displays the number of unique students in the dataset.

### Average Score

Shows the overall average student score.

### Attendance %

Shows the overall student attendance percentage.

### Score %

Calculates student performance based on:

`Score ÷ Maximum Score × 100`

### Performance Category

Students are categorized based on their score percentage into:

- Low
- Medium
- High
